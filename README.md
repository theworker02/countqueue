# countqueue

Count encode/decode helpers for queue payloads in pipelines.

**Site:** https://theworker02.github.io/countqueue/

## Install / run

```bash
git clone https://github.com/theworker02/countqueue.git
cd countqueue
node src/cli.js
node --test
```
